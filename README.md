# Cinee Pipeline

CEO automation pipeline for [cinee.com](https://cinee.com). Uses **OpenClaw** browser automation to run the founder's social media presence on X (Twitter) — researching AI filmmaking trends, posting hot takes, and replying to mentions — all autonomously with a Telegram-based human-in-the-loop review system.

## Architecture

```text
┌─────────────────────────────────────────────────┐
│               OpenClaw (Browser Agent)          │
│  Runs isolated cron jobs: search, post, reply   │
│  on x.com autonomously via browser automation   │
└──────────────────────┬──────────────────────────┘
                       │ REST calls
┌──────────────────────▼──────────────────────────┐
│            Node.js / Express (port 3000)        │
│                                                 │
│  /api/content-review/*     ← Telegram Review    │
│  /api/telegram/*           ← Telegram Webhook   │
│  /api/tools/db/posts       ← Post CRUD          │
│  /api/tools/db/replies     ← Reply CRUD          │
│  /api/tools/db/curation    ← AI film sources     │
│  /api/tools/db/persona     ← CEO stances         │
│  /api/tools/memory/*       ← Redis memory        │
│  /api/scheduler/*          ← Cron management     │
└──────────────────────┬──────────────────────────┘
                       │
              ┌────────▼────────┐
              │    MongoDB      │
              │  + Redis cache  │
              └─────────────────┘
```

**How it works:**

1. Scripts like `npm run cron:add-all` register isolated cron jobs in OpenClaw.
2. OpenClaw runs each job on schedule — it opens a browser, executes the prompt (search X, scrape notifications, draft content), then calls back to the Node.js REST API to persist results.
3. Content generated by OpenClaw (like new posts) is sent to a **Telegram Bot** for human review (`/api/content-review`). The human can approve, reject, edit, ask AI to rewrite, or schedule the post.
4. The Node.js server acts as the central API layer: MongoDB for structured data, Redis for short-term memory, and serves as the webhook receiver for Telegram interactions.

## Getting Started

### Prerequisites

- Node.js 18+
- MongoDB running locally (or provide `MONGO_URI`)
- Redis running locally (or provide `REDIS_URL`)
- Telegram Bot Token & Chat ID (for review notifications)
- [OpenClaw CLI](https://docs.openclaw.ai) installed and authenticated

### 1. Install & Configure

```bash
npm install
cp .env.example .env
# Edit .env with your values
```

Required environment variables:

| Variable | Description |
|---|---|
| `MONGO_URI` | MongoDB connection string |
| `REDIS_URL` | Redis connection string |
| `PUBLIC_API_URL` | Public URL of this server (used in OpenClaw prompts & Telegram webhook) |
| `FOUNDER_NAME` | CEO name for persona |
| `TELEGRAM_BOT_TOKEN` | Token from BotFather |
| `TELEGRAM_CHAT_ID` | Your Chat ID to receive reviews |

### 2. Start the Server

Start the app locally or in dev mode:
```bash
npm run dev
```

Remember to hook up your Telegram webhook by sending a POST request to `/api/telegram/setup` with your `webhook_url` (e.g., using ngrok for local development).

### 3. Register Cron Jobs

You can add all jobs at once:
```bash
npm run cron:add-all
```

Or you can manage them individually:
```bash
npm run cron:add:scrape            # scrape_x_notifications
npm run cron:add:reply             # reply_x_notifications
npm run cron:add:research-morning  # research_and_draft_morning
npm run cron:add:research-evening  # research_and_draft_evening
```

| Job | Schedule | What it does |
|---|---|---|
| `scrape_x_notifications` | Every hour at :20 | Scrape X notifications, evaluate & save to `/db/replies` |
| `reply_x_notifications` | Every hour at :40 | Reply to resolved mentions as CEO under 300 chars |
| `research_and_draft_morning` | 9 AM daily | Search X for AI film trends (Sora, Kling...), formulate draft |
| `research_and_draft_evening` | 9 PM daily | Search X for AI film trends (Sora, Kling...), formulate draft |

### 4. Verify

```bash
openclaw cron list                            # Check registered jobs
curl localhost:3000/api/health                # Server health
curl localhost:3000/api/status                # Daily stats
curl localhost:3000/api/telegram/status       # Telegram webhook status
```

## API Endpoints

### Telegram & Content Review
| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/telegram/setup` | Register the Telegram webhook |
| `POST` | `/api/telegram/webhook` | Receives queries and updates from Telegram |
| `GET` | `/api/telegram/status` | Current Telegram webhook status |
| `POST` | `/api/content-review/drafts` | Create draft & push to Telegram review |
| `PATCH` | `/api/content-review/drafts/:id/approve` | Approve a draft |
| `PATCH` | `/api/content-review/drafts/:id/schedule` | Schedule a draft |
| `POST` | `/api/content-review/drafts/:id/ai-rewrite` | Rewrite draft content via OpenClaw |

### Database CRUD (`/api/tools/db/`)
| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/db/posts` | Create a post |
| `GET` | `/db/posts` | List posts (`?status=&content_type=&limit=&skip=`) |
| `PATCH` | `/db/posts/:id` | Update post (status, metadata) |
| `POST` | `/db/replies` | Create replies |
| `GET` | `/db/replies` | List replies (`?status=draft,resolved&platform=x`) |
| `PATCH` | `/db/replies/:id` | Mark reply as replied |
| `POST` | `/db/persona` | Upsert CEO topic stance |
| `GET` | `/db/stats` | Today's pipeline statistics |
